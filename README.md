# Fanaka Noblewealth Advisory: Website

Multi-page static site (HTML/CSS/JS, no frameworks). English default, Kiswahili switcher. 25 service pages in 4 categories.

## Run
Open the folder in VS Code and use Live Server on `index.html` (or double-click it).

## Edit
Everything is generated by `build.py`. Edit the CONFIG block at the top (email, phone, WhatsApp, address, form endpoint, domain)
or any `T("English","Kiswahili")` text, then run `python3 build.py`. Header, mega-menu and footer are identical on every page.
Colours and 3D styles: `assets/css/style.css`.

## Service images
Each service card uses a 3D artwork tile. To use a photo, save it as `assets/img/services/<slug>.jpg`
(e.g. `money-market-fund.jpg`) and run `python3 build.py`. It replaces the artwork automatically.
Use images you own or that are licensed for commercial use.

## Hero video
Put `hero.mp4` (and optionally `hero.webm`) in `assets/video/`. Until then the word-art animation plays.

## Forms
With no FORM_ENDPOINT set, forms open the visitor's email app addressed to your EMAIL. For automatic delivery, set a Formspree or Netlify Forms URL in CONFIG.

## Before launch
Have a Kenyan lawyer review the legal pages, a native speaker review the Kiswahili, and confirm the licences or licensed partners behind each regulated service.
